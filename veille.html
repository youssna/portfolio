01 · Sujet

Mon sujet de veille

Pourquoi j'ai choisi d'étudier React et les SPA pour mon BTS SIO.

Pour ma veille technologique, j'ai choisi d'étudier la création de Single Page Applications (SPA) — des sites web qui fonctionnent comme des applications mobiles, sans rechargement de page. Ce type d'interface est aujourd'hui la norme dans la plupart des entreprises du secteur numérique.


Pour comprendre concrètement comment ces projets sont construits, j'ai centré ma veille sur React, la bibliothèque JavaScript la plus adoptée pour le front-end en 2024–2025 selon les sondages annuels Stack Overflow. Ce choix me permet d'anticiper les attentes du marché du travail à la sortie de mon BTS.

03 · Concepts

React expliqué simplement

Les deux notions clés pour comprendre ce qu'est React et pourquoi il est populaire.

🧰 C'est quoi une bibliothèque front-end ?

C'est un ensemble d'outils prêts à l'emploi. Au lieu de tout coder à la main, une bibliothèque comme React fournit des "briques" réutilisables qui permettent de construire une interface plus vite et de façon plus fiable.

🧩 Comment fonctionne React ?

React découpe le site en composants indépendants (un menu, un bouton, une carte). Si on modifie un composant, React met à jour uniquement la partie concernée de la page — sans tout recharger. C'est ce qui le rend très rapide.

📌 React, une bibliothèque ou un framework ?

Techniquement, React est une bibliothèque (elle gère uniquement l'interface visuelle), pas un framework complet. En pratique, elle est presque toujours associée à d'autres outils : Next.js pour le routage et le rendu côté serveur, TanStack Query pour la gestion des données, Tailwind CSS pour le style. On parle alors d'un "écosystème React".

💡 Pourquoi j'ai choisi React plutôt que Vue ou Angular ?

React est le choix le plus demandé sur le marché de l'emploi français. De plus, apprendre React permet d'accéder facilement à React Native pour le mobile, et à Next.js pour le rendu serveur — deux technologies très présentes en entreprise. C'est donc l'investissement le plus polyvalent pour démarrer une carrière web.

05 · Actualités

Les grandes mises à jour récentes

Les changements majeurs survenus entre 2024 et 2025, que je suis dans le cadre de ma veille.

Déc. 2024
Version majeure

🚀 Sortie officielle de React 19

Ce qui change : React 19 introduit le React Compiler, un outil qui optimise automatiquement les performances du site. Avant, les développeurs devaient ajouter manuellement des mécanismes pour éviter les ralentissements. Désormais, le compilateur le fait seul. Le code devient plus simple à écrire, et les sites plus rapides sans effort supplémentaire.

→ Lire l'annonce officielle
2024 Continu
Standardisation

⚡ Les React Server Components (RSC) généralisés

Ce qui change : Historiquement, React s'exécutait uniquement dans le navigateur. Les RSC permettent à certains composants de s'exécuter directement sur le serveur. Résultat : moins de code envoyé à l'utilisateur, chargement plus rapide sur mobile, et meilleur référencement Google (SEO). Next.js 14+ les utilise par défaut.

→ Comprendre les RSC
2024 React 19
Nouvelle fonctionnalité

📝 Gestion simplifiée des formulaires avec les "Actions"

Ce qui change : Avant, gérer un formulaire demandait d'écrire beaucoup de code : indicateur de chargement, gestion des erreurs, retour utilisateur... Les nouvelles "Actions" (et le hook useActionState) permettent de simplifier tout ça en quelques lignes. C'est l'une des améliorations les plus attendues des développeurs.

→ Voir la documentation
2025 En cours
Tendance 2025

🤖 Intégration de React avec les interfaces IA

Ce qui change : Vercel (l'entreprise derrière Next.js) développe le AI SDK, une bibliothèque qui permet d'intégrer facilement des fonctionnalités d'IA générative dans des applications React. De plus en plus d'offres d'emploi mentionnent cette compétence en 2025.

→ Voir le Vercel AI SDK
06 · Prévisions

Prévisions et avenir de React

Ce que j'anticipe en analysant les tendances actuelles du marché.

D'après mon analyse des mises à jour récentes et des tendances de l'écosystème, voici les évolutions que je prévois pour les prochaines années :

🤖 Automatisation des tâches répétitives

Le React Compiler marque le début d'une tendance : les outils feront de plus en plus d'optimisations à notre place. Le développeur se concentrera davantage sur la logique métier que sur la performance technique.

🌐 Le Full-Stack avec Next.js

Next.js 15+ continue de fusionner front-end et back-end dans une seule application React. La frontière entre développeur front et full-stack devient de plus en plus floue.

📱 React Native & applications cross-platform

Apprendre React ouvre la porte à React Native (mobile iOS/Android). En 2025, les entreprises cherchent de plus en plus des profils capables de toucher à la fois le web et le mobile.

⚔️ La montée de Svelte et Astro

Des alternatives comme Svelte et Astro gagnent en popularité pour les sites vitrine et les blogs. React reste dominant sur les applications complexes, mais la concurrence pousse l'écosystème à innover.

Bilan personnel

🎯

Une veille orientée vers la préparation professionnelle

Au début de mon BTS, j'ai volontairement choisi de coder mes projets "à la main", sans framework (comme Loca'Vélo en PHP). Cela m'a permis de construire des bases solides en HTML, CSS, JavaScript et PHP natif — des fondations indispensables avant d'utiliser un framework.

Aujourd'hui, je suis en phase d'apprentissage actif de React. Je lis la documentation officielle, je suis des tutoriels pratiques, et je crée de petits composants pour comprendre la logique de l'outil. Je n'ai pas encore de projet React en production, mais cette veille me permet d'arriver sur le marché du travail avec le vocabulaire, les concepts et les standards attendus par les entreprises.

L'objectif : être opérationnel sur React dès mon premier poste, sans avoir besoin d'un long temps de formation.
