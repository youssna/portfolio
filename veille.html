Veille Technologique

Découverte et prise en main du Framework Front-End : React.

🎯

Pourquoi avoir choisi cette veille ?

Au début de ma formation, je me suis entraîné à tout coder "à la main", sans framework (comme pour mon projet Loca'Vélo). C'était nécessaire pour bien comprendre les bases de la programmation.

Maintenant que j'ai acquis ces bases, mon objectif professionnel est de me familiariser avec les outils utilisés en entreprise. J'ai donc choisi de suivre l'actualité de React, l'outil le plus demandé aujourd'hui pour créer des sites web.

Comprendre React simplement

Ce qu'il faut savoir sur cette technologie.

C'est quoi un Framework ?

C'est tout simplement une boîte à outils prête à l'emploi. Au lieu de réinventer la roue et de coder un menu ou un système de sécurité à partir de zéro, un framework nous fournit une base de travail solide et des règles à suivre pour coder plus vite et sans erreurs.

C'est quoi React ?

Créé par Facebook, React est une boîte à outils spécialisée dans le visuel (le Front-End). Son rôle est de gérer uniquement ce que l'utilisateur voit et touche sur son écran (les boutons, les formulaires, les animations).

Comment ça marche ? (La méthode Lego)

L'utilisation de React repose sur un concept très simple : les composants.

Construire le site comme des Legos

Plutôt que de coder une page web entière d'un seul coup, avec React, on crée de petits blocs indépendants (un bloc pour le menu, un bloc pour un bouton, un bloc pour une image). On appelle ça des Composants.

Ensuite, on assemble ces blocs pour former la page finale. L'avantage ? Si je veux changer la couleur de mon bouton, je le modifie une seule fois dans mon bloc "bouton", et il se mettra à jour automatiquement partout sur mon site.

Comparaison : React VS PHP Classique

Pourquoi les entreprises préfèrent React aujourd'hui ?

Le critère Un site en PHP Classique Un site avec React
Le chargement À chaque fois qu'on clique sur un lien, toute la page devient blanche et se recharge complètement. Instantané. La page ne se recharge jamais. Seule la petite partie modifiée (ex: une image) se met à jour à l'écran.
L'expérience utilisateur Le site ressemble à un site web traditionnel. Le site est tellement fluide qu'il donne l'impression d'utiliser une véritable application mobile (comme Instagram).

🔮 Prévisions et Avenir de React

D'après ma veille, l'avenir de React (avec l'arrivée récente de la mise à jour React 19) se tourne vers l'automatisation.

Les prochaines années vont simplifier encore plus le travail des développeurs en supprimant du code inutile, et l'Intelligence Artificielle va de plus en plus s'intégrer directement dans les outils pour nous aider à assembler ces "composants" encore plus vite. React s'associe aussi avec d'autres technologies (comme Next.js) pour que les sites soient mieux classés sur Google.
