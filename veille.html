Veille Technologique

Observation et étude du framework Front-End : React.

⚛️

1. Mon sujet de veille : React

Pour ma veille technologique, je me concentre sur React. C'est l'outil numéro un utilisé en entreprise pour créer la partie visible des sites web. Mon but est de comprendre théoriquement comment sont faits les sites modernes et ultra-rapides d'aujourd'hui, afin de me préparer au marché du travail.

2. L'histoire et l'évolution de React

D'où vient cet outil et comment s'est-il imposé ?

Année L'événement marquant L'impact
2013 Création par Facebook (Meta) Jordan Walke, un ingénieur de Facebook, crée React car le code de leur site devenait trop lourd et lent à charger.
2015 Passage en Open-Source Facebook rend l'outil public et gratuit. Le monde entier commence à l'utiliser pour créer des sites web rapides.
Aujourd'hui Le standard de l'industrie React est devenu indispensable. De très grandes entreprises comme Netflix, Airbnb ou Uber l'utilisent pour leurs interfaces.

3. Comprendre React simplement

Les concepts de base sans termes compliqués.

C'est quoi un Framework / Bibliothèque ?

C'est une boîte à outils. Au lieu de tout coder à partir de zéro, cet outil nous donne des bases solides et des règles pour coder plus vite et éviter les erreurs.

La méthode des Legos

React fonctionne comme des Legos. On découpe le site en petits blocs indépendants (un bloc pour le menu, un pour un bouton). Si on change la couleur du bouton, il se met à jour partout sur le site d'un seul coup sans recharger la page.

4. Les dernières actualités de React

Les informations récentes que j'ai relevées lors de ma veille.

L'adoption du React Compiler

Mini-résumé : Un nouvel outil interne gère désormais la vitesse du site automatiquement. Le développeur n'a plus besoin d'écrire du code complexe pour éviter les ralentissements, la machine le fait à sa place.

La norme des "Server Components"

Mini-résumé : De plus en plus, le code React ne s'exécute plus sur le téléphone de l'utilisateur, mais directement sur le serveur. Cela permet d'afficher les pages beaucoup plus rapidement, même avec une mauvaise connexion internet.

L'IA qui génère des interfaces

Mini-résumé : De nouveaux outils basés sur l'intelligence artificielle permettent aujourd'hui de décrire un bouton ou un menu avec des mots, et l'outil génère instantanément le code React correspondant à copier-coller.

🔮 5. Prévisions et Avenir

En observant ces actualités, je prévois que le code React va devenir de plus en plus simple à écrire. Les tâches répétitives et l'optimisation de la vitesse seront gérées par la machine. Avec l'aide grandissante de l'Intelligence Artificielle pour générer le visuel, le rôle du développeur de demain sera surtout d'assembler ces "blocs de Lego" et de vérifier la logique de l'application, plutôt que de tout taper à la main.

🎯

6. Bilan : Pourquoi ce choix et où j'en suis ?

Au début de mon BTS, j'ai voulu coder mes projets (comme Loca'Vélo) entièrement en PHP natif. C'était un choix volontaire pour comprendre les bases de la programmation web de A à Z.

Aujourd'hui, pour ma veille technologique, j'ai choisi de m'intéresser à React pour anticiper mon avenir professionnel. Pour être totalement transparent, je n'ai jamais utilisé React, pas même pour de petits tests.

Mon apprentissage est pour le moment 100% théorique. Je lis les articles et je surveille l'évolution de l'outil pour connaître son vocabulaire, son histoire et comprendre sa logique globale. Mon but est d'être prêt théoriquement avant de me lancer dans la pratique sur de futurs projets en entreprise.
