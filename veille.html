1. Mon sujet de veille : React

Pour ma veille technologique, je me concentre sur React. C'est l'outil numéro un utilisé en entreprise pour créer la partie visible des sites web. Mon but est de comprendre comment faire des sites ultra-rapides qui ne se rechargent jamais (comme une application mobile), afin de me préparer au marché du travail.

Documentation et Vidéos

3. Comprendre React simplement

Les concepts de base sans termes compliqués.

C'est quoi un Framework ?

C'est une boîte à outils. Au lieu de tout coder à partir de zéro, un framework nous donne des bases solides et des règles pour coder plus vite et éviter les erreurs.

La méthode des Legos

React fonctionne comme des Legos. On découpe le site en petits blocs indépendants (un bloc pour le menu, un pour un bouton). Si on change la couleur du bouton, il se met à jour partout sur le site d'un seul coup.

4. Comparaison : React VS PHP sans framework

La différence avec ce que je faisais au début de ma formation.

Critère Un site codé en PHP Classique Un site avec React
Le chargement À chaque fois qu'on clique sur un lien, l'écran devient blanc un instant et la page entière se recharge. Instantané. La page ne se recharge jamais. On remplace juste le petit bout d'écran qui a changé.
Organisation du code Le HTML et le PHP sont souvent mélangés dans de longs fichiers, ce qui devient dur à relire sur de gros projets. Tout est rangé dans de petits blocs (composants). C'est très facile à lire et parfait pour travailler en équipe.

5. Les dernières nouveautés de React

Les informations récentes que je surveille en ce moment.

🚀 L'arrivée de React 19

Mise à jour majeure

L'information : La version 19 de React apporte un outil appelé "Compiler". Avant, il fallait écrire du code spécial pour que le site ne ralentisse pas. Maintenant, cet outil fait les optimisations tout seul en arrière-plan.

📝 Formulaires plus faciles

Nouvelle fonctionnalité

L'information : Gérer l'envoi d'un formulaire de connexion était un peu long à coder avec React. Une nouvelle fonction appelée "Actions" vient d'arriver pour simplifier tout ça avec beaucoup moins de code.

⚡ Le Server-Side

Tendance actuelle

L'information : De plus en plus, React s'exécute côté serveur plutôt que sur le téléphone de l'utilisateur. Cela permet d'avoir des sites qui chargent plus vite et qui sont mieux trouvés par Google (SEO).

🔮 6. Prévisions et Avenir

En voyant ces nouveautés, je prévois que le code React va devenir de plus en plus court et simple à écrire. L'outil va s'occuper seul des problèmes de vitesse. L'Intelligence Artificielle va aussi beaucoup nous aider à générer ces "blocs de Lego" (les composants) de plus en plus vite. Le rôle du développeur sera surtout de bien les assembler.

7. Bilan : Pourquoi cette veille et où j'en suis ?

Au début de mon BTS, j'ai voulu coder mes projets (comme Loca'Vélo) entièrement en PHP classique. C'était un choix volontaire pour bien comprendre les bases de la programmation web, sans utiliser de raccourcis.

Je n'ai pas encore utilisé React sur un vrai projet terminé. Actuellement, je suis dans une phase que j'appelle mon "bac à sable". Je m'entraîne à faire de petites choses simples pour comprendre l'outil. Mon objectif avec cette veille, c'est d'être prêt, de connaître le vocabulaire et les nouveautés pour utiliser React sur mes futurs projets en entreprise.
